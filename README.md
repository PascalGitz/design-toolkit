# Idea
The idea of this repository is to provide a collection of calculation sheets used by structural engineers.
It aims to move away from the industry standard of relying on locally stored Excel sheets that often function like “black boxes.”
By consolidating these calculation tools in a shared repository, the quality (in terms of usability and background information) is expected to improve. Additionally, the collaborative approach should reduce errors, as more engineers can review, use, and contribute to the content.

# Structure
The repository is organized by engineering topics.
All calculation sheets are implemented using [Calcpad](https://calcpad.eu/), whose open-source nature is expected to ensure long-term sustainability and future-proofing.

# Installation
The best way to use the desing-toolkit is to clone the repository. The cloned repository will sync with the changes, ergo it provides an always up-to-date design-toolkit.
The process of cloning is easily setup using [GitHub-Desktop](https://desktop.github.com/download/).

# Contributing
Contributions are very welcome and needed!  
This repository is intended to grow through collaboration, and you do **not** need to be an expert in Git to contribute.

Below is a simple step-by-step guide using **GitHub Desktop**, which avoids working in the command line.

### 1. Install Required Tools
- Install https://desktop.github.com/download/
- Create a free https://github.com/ account if you don’t have one


### 2. Clone the Repository
1. Open **GitHub Desktop**
2. Click **File → Clone repository**
3. Select this repository (or paste its URL)
4. Choose a local folder on your computer
5. Click **Clone**

You now have a local copy and it will stay up to date with the repository.



### 3. Create a New Branch (Important)
A new branch is basically a copy of the repository.
Before making changes:

1. In GitHub Desktop, click on **Current Branch**
2. Select **New Branch**
3. Give it a descriptive name, e.g.:

`beam-calculation-update add-concrete-section-sheet`

4. Click **Create Branch**

This keeps your work separate from the main version.


### 4. Make Your Changes
- Add or edit calculation sheets using **Calcpad**
- Place files in the appropriate topic folder
- Use clear and consistent naming
- Add comments in the file where useful for understanding


### 5. Commit Your Changes
1. Go back to **GitHub Desktop**
2. You will see your modified files listed
3. Add a short description, e.g.:

`Added new steel beam calculation sheet`

4. Click **Commit to [your-branch-name]**


### 6. Push Your Changes
1. Click **Push origin** in GitHub Desktop
2. Your changes are now uploaded to GitHub


### 7. Create a Pull Request
1. Click **Create Pull Request** (in GitHub Desktop or your browser)
2. Add a short description:
- What was added or changed?
- Why is it useful?
3. Submit the pull request

### 8. Review & Merge
- Your contribution will be reviewed by the owner of the repository
- Feedback may be provided if needed
- Once approved, it will be merged into the main repository
