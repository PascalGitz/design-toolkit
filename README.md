# Idee
Die Idee dieses Repositorys ist es, eine Sammlung von Berechnungsblättern für Bauingenieure bereitzustellen.  
Ziel ist es, sich vom branchenüblichen Ansatz zu lösen, bei dem lokale Excel-Dateien verwendet werden, die oft als „Blackbox“ funktionieren.  

Durch die Bündelung dieser Berechnungswerkzeuge in einem gemeinsamen Repository soll die Qualität (hinsichtlich Benutzerfreundlichkeit und Hintergrundinformationen) verbessert werden.  
Zudem soll der kollaborative Ansatz Fehler reduzieren, da mehr Ingenieure die Inhalte prüfen, nutzen und weiterentwickeln können.


# Struktur
Das Repository ist nach ingenieurtechnischen Themen organisiert.  

Alle Berechnungsblätter werden mit [Calcpad](https://calcpad.eu/) umgesetzt, dessen Open-Source-Charakter langfristige Nachhaltigkeit und Zukunftssicherheit gewährleisten soll.  
Das Repository sowie alle Inhalte werden zunächst auf Deutsch verfasst.



# Installation
Die beste Möglichkeit, das *design-toolkit* zu nutzen, ist das **Clonen des Repositorys**.  
Das geklonte Repository synchronisiert sich mit Änderungen und stellt somit ein stets aktuelles *design-toolkit* bereit.  

Das Clonen lässt sich einfach mit [GitHub Desktop](https://desktop.github.com/download/) einrichten.

# Mach mit!
Beiträge sind sehr willkommen und ausdrücklich erwünscht!  
Dieses Repository lebt von Zusammenarbeit.

Im Folgenden findest du eine einfache Schritt-für-Schritt-Anleitung mit basierend [GitHub Desktop](https://desktop.github.com/download/).



### Benötigte Tools installieren
- Installiere [GitHub Desktop](https://desktop.github.com/download/)
- Erstelle einen kostenlosen https://github.com/ Account, falls du noch keinen hast

### Repository clonen
1. Öffne [GitHub Desktop](https://desktop.github.com/download/)
2. Klicke auf **File → Clone repository**
3. Wähle dieses Repository aus (oder füge die URL ein, siehe grüner Button auf der Startseite)
4. Wähle einen lokalen Ordner auf deinem Computer
5. Klicke auf **Clone**

Du hast nun eine lokale Kopie, die sich automatisch aktuell hält.



### Neuen Branch erstellen (Wichtig)
Ein neuer Branch ist im Prinzip eine Kopie des Repositorys.  

Bevor du Änderungen machst:

1. Klicke in GitHub Desktop auf **Current Branch**
2. Wähle **New Branch**
3. Vergib einen aussagekräftigen Namen, z. B.:

`balkenberechnung ueberarbeitung`

4. Klicke auf **Create Branch**

So bleiben deine Änderungen vom Hauptstand getrennt.



### Änderungen durchführen
- Berechnungsblätter mit **Calcpad** hinzufügen oder bearbeiten
- Dateien im passenden Themenordner ablegen
- Klare und konsistente Benennung verwenden
- Bei Bedarf Kommentare zur besseren Verständlichkeit hinzufügen



### Änderungen committen
1. Gehe zurück zu [GitHub Desktop](https://desktop.github.com/download/)
2. Deine geänderten Dateien werden angezeigt
3. Füge eine kurze Beschreibung hinzu, z. B.:

`Neue Balkenberechnung hinzugefuegt`

4. Klicke auf **Commit to [dein-branch-name]**



### Änderungen pushen
1. Klicke auf **Push origin** in GitHub Desktop
2. Deine Änderungen werden auf GitHub hochgeladen


### Pull Request erstellen
1. Klicke auf **Create Pull Request** (in GitHub Desktop oder im Browser)
2. Füge eine kurze Beschreibung hinzu:
   - Was wurde hinzugefügt oder geändert?
   - Warum ist es nützlich?
3. Sende den Pull Request ab


### Review & Merge
- Dein Beitrag wird vom Owner des Repositorys geprüft
- Falls nötig, erhältst du Feedback
